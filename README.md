# О!дин запрос — прототип travel-агента

Демо полного пути от свободного запроса до собранной поездки и имитации бронирования. Интерфейс и каталог работают на синтетических данных: цены, наличие мест, погода, рейсы, отели и трансферы не являются актуальными предложениями Островка.

## Запуск в Docker

Нужны Docker и Docker Compose:

```powershell
Copy-Item agent\.env.example .env
# Укажите свой ключ DeepSeek в LLM_API_KEY в .env.
docker compose up --build
```

Откройте <http://localhost:5173>. В одном Compose-проекте запускаются React-клиент, Node.js API и Python travel-agent. Проверка Node API — <http://localhost:3001/api/health>, agent API — <http://localhost:8000/api/health>.

## Запуск без Docker

Требуются Node.js 20+, Python 3.12+ и [uv](https://docs.astral.sh/uv/). Скопируйте настройки агента и заполните `LLM_API_KEY`, если нужна настоящая модель:

```powershell
Copy-Item agent\.env.example agent\.env
```

Запустите каждый сервис в отдельном терминале:

```powershell
cd agent
uv sync
uv run  odin
```

```powershell
cd server
npm ci
npm run dev
```

```powershell
cd client
npm ci
npm run dev
```

Vite проксирует `/api` на локальный backend. Интерфейс откроется на <http://localhost:5173>.

## Сценарий демо

1. Опишите поездку обычным сообщением.
2. Если агент предложит направления, выберите карточку под его ответом или укажите номер в чате.
3. Отправьте уточнение (например, «на два дня позже», «бюджет меньше» или «едем с собакой») — план будет пересобран.
4. Нажмите «Перейти к оформлению», проверьте корзину, затем отдельно подтвердите имитацию оплаты.

По умолчанию настроен DeepSeek V4.1 Flash (`https://api.deepseek.com`, модель `deepseek-flash`, с поддержкой вызова инструментов). Получите ключ на [платформе DeepSeek](https://platform.deepseek.com/api_keys) и добавьте его в локальный `.env` как `LLM_API_KEY`; ключ не нужно отправлять в чат или коммитить. Системные инструкции задают агенту работу с каталогом, ограничения направлений, сценарий выбора карточек, честное описание синтетических цен и пошаговое оформление. Без ключа остаётся детерминированный демо-режим. Каталог, цены, погода, предложения и оформление пока синтетические: авиабилеты, ж/д билеты, отели и списание денег реальными поставщиками не подключены. В плане встроен интерактивный виджет Яндекс Карт для поиска отеля или направления, а маршрут можно открыть отдельно в Яндекс Картах. Сессии хранятся в памяти и сбрасываются при перезапуске агента.

## Архитектура

- `client/` — React + Vite, одностраничный русскоязычный интерфейс.
- `server/` — Node.js + Express, BFF-адаптер между интерфейсом и агентом.
- `agent/` — встроенный Python/FastAPI travel-agent: LLM-цикл, доменная логика, планировщик, checkout и синтетический каталог.
- `docker-compose.yml` — запуск всех трёх сервисов; nginx проксирует `/api` через Node backend к Python-агенту.

### API агента

- `POST /api/agent/message` — `{ "sessionId?": "...", "message": "..." }`; ведёт диалог с Python-агентом.
- `POST /api/agent/select` — `{ "sessionId": "...", "hotelId": "..." }`; выбирает отображённый вариант.
- `POST /api/agent/checkout` — `{ "sessionId": "..." }`; сначала создаёт корзину, повторное явное подтверждение имитирует оплату.

Node backend подключается к Python-сервису через `AGENT_BASE_URL` (в Compose уже настроен). Самостоятельно можно запустить `agent/` командой `uv run odin`; сервер слушает порт 8000.
