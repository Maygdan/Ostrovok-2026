О!дин запрос агент для путешествий

Как это работает

  1. Одно сообщение. Напишите, чего хотите, как другу: куда, когда, с кем и за какие деньги.
  2. Понимание. Агент вытащит явные и скрытые требования и спросит только необходимое.
  3. Выбор с объяснением. Направления, отели, дорога и трансферы сравниваются не только по цене: почему подходит, чем пожертвовали, какие риски.
  4. Один план. Стыковки прилёта, заселения и трансфера проверяются; условия меняются — план пересобирается, а не ищется заново.
  5. Корзина и оплата — имитация, деньги не списываются.
Рейсы, отели и цены — синтетические данные для демонстрации; оплата — имитация.
